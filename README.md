# Offline Software Setup Guide

A beginner-friendly, step-by-step guide to setting up a Windows PC for building
offline desktop software in Python, with a small example patient-records app.

## What's inside

- **Setup guide (PDF):** installing Python, VS Code, the Python extension, Pillow
  and DB Browser for SQLite, choosing the right interpreter, and packaging an app
  as an .exe with PyInstaller. Every step explains *why* it's needed.

## Requirements

- Windows 10 or 11
- Python 3.12 or newer
- Internet only during installation; the app itself runs fully offline

## Data and privacy

The example app stores its data in `mini_clinic.db`, next to the program.
Never commit real patient databases to a repository.
